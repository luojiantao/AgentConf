## 人工判断标准

以下标准用于判断方案是否值得确认，不代表代码已经实现：

- [ ] 问题真实存在，且目标值得投入成本。
- [ ] 推荐方案比至少一个替代方案更适合当前约束。
- [ ] 目标、非目标、边界和不变量清楚。
- [ ] 主要失败方式和风险可以接受。
- [ ] 没有未经授权的业务规则、技术选型或范围扩大。
- [ ] 已知事实、假设和待验证事项已区分。
- [ ] 人工确认后可以把方案直接交给 `$ai-plan-executor`；如需预先审查执行细节，也可以交给 `$ai-plan-converter`。

## 后续执行说明

人工确认后：

1. 将 `方案状态` 更新为 `已确认`，或在调用消息中明确指定本文档已获确认。
2. 默认直接使用 `$ai-plan-executor` 读取本文档；executor 会先在内部补齐准确文件、类型、函数、实现步骤、静态校验和运行验证，再执行代码修改。
3. 如果 master 希望在代码修改前审查 executor-ready 细节，可以先单独使用 `$ai-plan-converter`，再将生成的执行方案交给 `$ai-plan-executor`。
4. 无论选择哪条路径，人工确认前都不得开始转换或执行。
